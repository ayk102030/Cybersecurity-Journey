# 🐧 Lab 11: Advanced Text Processing with `awk` & `sed`

When managing logs, parsing tool outputs, or auditing live configurations in Linux, basic text tools like `cut` can fall short. As a penetration tester, incident responder, or system administrator, you must be able to parse dynamically spaced outputs and modify configuration text efficiently on the fly. This lab covers **`awk`** (the ultimate whitespace parser) and **`sed`** (the stream text editor).

---

## 🛠️ Part 1: Advanced Data Processing via `awk`

### ⚙️ The Technical Difference: Why `awk` instead of `cut`?
The `cut` utility is highly effective if your data columns are split by a single, predictable character (such as a colon `:` or a comma `,`). However, when columns are separated by an unpredictable mix of tabs and spaces—sometimes 1 space, sometimes 5 spaces—like the raw tables generated by `netstat` or `ps aux`, `cut` fails completely. That is where `awk` shines.

By default, `awk` automatically treats any amount of arbitrary whitespace (spaces or tabs) as a column separator. It maps these columns to programmable variables out of the box:
* **`$1`**: Represents the 1st column.
* **`$2`**: Represents the 2nd column.
* **`$4`**: Represents the 4th column.
* **`$0`**: Represents the entire line.

---

### 🛡️ The Cybersecurity Perspective

#### 🟢 For the Defender (Log Analysis)
Imagine analyzing an active web server access log under a suspected Denial of Service (DoS) attack. The log lines are dense with browser metadata, timestamps, and request formats. You urgently need to isolate just the column containing the source IP address (e.g., column 4) to pipe it into your firewall and block the threat. `awk` performs this extraction instantly.

#### 🔴 For the Attacker (Automated Reconnaissance)
When running large-scale network scans, you are often faced with thousands of lines of output. If you want to automatically carve out only the open port numbers and pass them directly into a downstream exploitation tool, `awk` is the tool of choice to accurately peel away the formatting noise and harvest the raw numerical values.

---

### 🎯 Practical Application: Parsing Sockets
Let's apply `awk` to filter the network connection table. Our goal is to isolate only the 4th column (**`Local Address`**), which contains your machine's internal IP and open ports, while completely discarding everything else (PIDs, states, etc.).

Execute this pipeline command in your terminal:
```bash
netstat -pnat | awk '{print $4}'
```

#### 🔬 Behind-the-Scenes Mechanics:
1. **`netstat -pnat`**: Generates a network connection grid heavily padded with irregular spacing.
2. **`|` (The Pipe)**: Feeds that entire table directly into `awk`.
3. **`awk '{print $4}'`**: Evaluates the output line by line, cleanly jumps over the irregular whitespace barriers, and prints *only* the contents of the 4th column aligned with precision.

## 🪚 Part 2: The Stream Editor (`sed`)

`sed` stands for **Stream Editor**. It is a command-line text editor that works without opening a graphical user interface (unlike `nano` or `vim`). It reads input stream data line by line, applies structural modifications (such as search, replace, delete, or insert), and outputs the altered text.

### 📝 General Syntax
```bash
sed [OPTIONS] 'command' file.txt
```

---

### 💡 Core Operational Use Cases

Imagine we have a text file named `test.txt` with the following content:
```text
I like Linux
Linux is great
```

#### 1️⃣ Substitute the First Occurrence in a Line
To find the word "Linux" and replace it with "Ubuntu":
```bash
sed 's/Linux/Ubuntu/' test.txt
```
* **Output:**
  ```text
  I like Ubuntu
  Ubuntu is great
  ```
  *(The `s` flag stands for **substitute**. It updates only the very first match it runs into on each line).*

#### 2️⃣ Global Substitution (All Occurrences)
If a single line contains the word multiple times and you want to replace *every single match*, append the **`g`** (**global**) modifier:
```bash
sed 's/Linux/Ubuntu/g' test.txt
```

#### 3️⃣ Delete Specific Lines
To remove a complete line based on its index (for example, deleting line number 2):
```bash
sed '2d' test.txt
```
  *(The `d` flag stands for **delete**).*

#### 4️⃣ Print Specific Lines Only
To inspect an isolated segment of a massive script or document (for example, viewing only line 3):
```bash
sed -n '3p' test.txt
```
  * **`-n`**: Suppresses the default behavior of printing every line.
  * **`p`**: Stands for **print**, ordering the tool to display only the requested target line.

#### 5️⃣ Direct In-Place Modification (Saving Changes)
By default, `sed` safely previews the output in your terminal without changing the original file. To write those modifications directly back into the source file itself, apply the **`-i`** (**in-place**) option:
```bash
sed -i 's/Linux/Ubuntu/g' test.txt
```

---

### 📊 `sed` Reference Guide Summary

| Option / Command | Purpose | Action Profile |
| :---: | :--- | :--- |
| **`s`** | Substitute | Replaces a search string with a new string. |
| **`g`** | Global | Works with `s` to replace all matches on a line instead of just the first. |
| **`d`** | Delete | Deletes targeted lines entirely. |
| **`p`** | Print | Displays targeted text blocks. |
| **`-n`** | Suppress | Inhibits standard output; typically paired with `p`. |
| **`-i`** | In-place | Overwrites and saves changes directly to the target file. |

## 🏆 Part 3: The Text Processing Trifecta

Understanding when to deploy each tool prevents overcomplicating your command-line operations:

```text
               [ Text Input Stream ]
                         |
                +--------+--------+
                |                 |
             [cut]              [awk]
         Isolate columns     Isolate columns
         via fixed single    via irregular or
         delimiters (:,).    dynamic whitespaces.
                                  |
                                  v
                               [sed]
                        Modify, substitute, or 
                        delete strings inline.
```

* **`cut`**: Best for slicing simple columns or character strings based on a predictable, single-character separator (like parsing colons out of `/etc/passwd` or commas out of a `.csv` file).
* **`awk`**: Best for advanced parsing, filtering complex whitespace data grids (like tables from system utilities like `netstat` or `ps`), or evaluating programmatic rules and matching criteria.
* **`sed`**: Best for mutating or editing files directly from the command line (such as searching and automating configuration updates) without ever opening an interactive text editor.

---

🏁 **Summary for your Security Notebook:**
* `awk` handles dynamic formatting smoothly because it naturally treats any arbitrary space or tab pattern as a column divider.
* `sed` edits data streams programmatically, enabling quick script adjustments, variable overrides, and targeted line deletions using the `-i` flag for in-place updates.
